## English

### Changed

- The release workflow now builds Windows x64, Windows ARM64, Linux x64, macOS Apple Silicon and macOS Intel in parallel and attaches every installer, plus the multi-platform updater manifest, to the same release. ([#49](https://github.com/mantoujun12/astrbot-launcher-vue/pull/49))
- The instance tab toolbar now shows start/stop/restart quick-actions in place of the status chip, like a browser toolbar. ([#53](https://github.com/mantoujun12/astrbot-launcher-vue/pull/53))

## 中文

### 变更

- 发布工作流现在会并行构建 Windows x64、Windows ARM64、Linux x64、macOS Apple Silicon 与 macOS Intel，并把全部安装包和多平台更新清单附加到同一个 Release。（[#49](https://github.com/mantoujun12/astrbot-launcher-vue/pull/49)）
- 实例标签页工具栏现在以浏览器快捷按钮的形式提供启动/停止/重启操作，取代原有的状态徽章。（[#53](https://github.com/mantoujun12/astrbot-launcher-vue/pull/53)）
