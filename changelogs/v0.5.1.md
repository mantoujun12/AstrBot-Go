## English

### Security

- Hardened the Tauri configuration: disabled `withGlobalTauri`, narrowed the opener permission to `allow-open-url`, removed unused `log` and `window-state` capability permissions, and dropped the unused `tauri-plugin-process` dependency. ([#121](https://github.com/mantoujun12/AstrBot-Go/pull/121))

### Changed

- Moved large file IO and blocking network probes (version archive extraction, instance directory cleanup, lock checks, and port probing) off the async runtime onto the blocking thread pool. ([#123](https://github.com/mantoujun12/AstrBot-Go/pull/123))
- Separated the display of application name + version and repository link in "Settings → About".

### Removed

- Removed pre-release compatibility and migration paths ([#118](https://github.com/mantoujun12/AstrBot-Go/pull/118)): the legacy launcher data-directory migration wizard, `data.redb` and TOML config/manifest import, the old `mainland_acceleration` preset conversion, and legacy task-history and Python directory migrations.

### Fixed

- Fixed task-center entries getting stuck as "Running" forever when an asynchronous task's work panicked: the task is now finalized as failed and its target can be submitted again immediately. ([#124](https://github.com/mantoujun12/AstrBot-Go/pull/124))
- Resolved all open code scanning alerts: annotated Windows-only and reserved system-proxy items to silence clippy dead-code warnings, removed a redundant clone in the backup module, and restricted GITHUB_TOKEN permissions in the coverage workflow. ([#116](https://github.com/mantoujun12/AstrBot-Go/pull/116))
- Fixed narrow-window layout and window chrome: instance table rows align their names and actions correctly, the home content no longer reserves unused space for the mobile menu at intermediate widths, the temporary sidebar hides its non-functional collapse button, and the sidebar and title bar now share a smooth, opaque background instead of showing the page through Mica. ([#117](https://github.com/mantoujun12/AstrBot-Go/pull/117))
- Guarded against duplicate submissions in the frontend: a backup being restored can no longer be deleted, download pause/resume and stop buttons ignore rapid double clicks, and quitting the launcher from the tray now uses the same click-again confirmation as stopping an instance. ([#122](https://github.com/mantoujun12/AstrBot-Go/pull/122))
- Surfaced frontend event-subscription and polling failures: the resource monitor now shows an error state with retry instead of frozen charts, and the log and task pages expose subscription/list failures with a retry action. ([#126](https://github.com/mantoujun12/AstrBot-Go/pull/126))
- Fixed instance discovery process plumbing: discovery subprocesses no longer stall on an unread stderr pipe and get falsely reported as unavailable, and the timeout kill path no longer leaks zombie processes. ([#125](https://github.com/mantoujun12/AstrBot-Go/pull/125))
- Redacted local paths and raw URLs embedded in archive-extraction and network error messages, and replaced the empty error text shown when a required backup file is missing with a specific description. ([#120](https://github.com/mantoujun12/AstrBot-Go/pull/120))
- Made critical cache/config writes atomic (GitHub releases cache, data-directory override) and cleaned up leftover `.restore-rollback-*` directories before a new restore. ([#119](https://github.com/mantoujun12/AstrBot-Go/pull/119))

## 中文

### 安全

- 加固 Tauri 配置：关闭 `withGlobalTauri`，将 opener 权限收窄为 `allow-open-url`，移除未使用的 `log` 与 `window-state` 能力权限，并删除未使用的 `tauri-plugin-process` 依赖。（[#121](https://github.com/mantoujun12/AstrBot-Go/pull/121)）

### 变更

- 将大文件 IO 与阻塞网络探测（版本压缩包解压、实例目录清理、锁文件检查、端口探测）移出异步运行时，改为在阻塞线程池中执行。（[#123](https://github.com/mantoujun12/AstrBot-Go/pull/123)）
- 将 “设置 → 关于” 中，显示应用名称+版本与仓库跳转，进行分隔。

### 移除

- 移除面向预发布旧版本的兼容与迁移逻辑：旧版启动器数据目录迁移向导、`data.redb` 与 TOML 配置/清单导入、旧 `mainland_acceleration` 预设转换，以及旧任务记录与 Python 目录迁移。（[#118](https://github.com/mantoujun12/AstrBot-Go/pull/118)）

### 修复

- 修复异步任务的工作过程发生 panic 时，任务中心条目永久停留在“运行中”的问题：任务现在会立即终结为失败，其目标也可以马上重新提交。（[#124](https://github.com/mantoujun12/AstrBot-Go/pull/124)）
- 修复了全部 open 状态的代码扫描告警：为 Windows 专属与系统代理预留代码标注 dead_code、移除备份模块中的冗余 clone，并为 coverage 工作流限制 GITHUB_TOKEN 权限。（[#116](https://github.com/mantoujun12/AstrBot-Go/pull/116)）
- 修复窄窗口下的布局与窗口效果：实例表格行的名称与操作区正确对齐，中等宽度下主内容不再为移动端菜单预留空白，临时侧边栏不再显示无效的伸缩按钮，侧边栏与标题栏统一为平滑过渡的不透明底色，不再透出页面内容。（[#117](https://github.com/mantoujun12/AstrBot-Go/pull/117)）
- 修复前端重复提交问题：恢复中的备份不再允许删除，版本下载的暂停/继续与停止按钮忽略快速连点，托盘退出启动器改为与停止实例一致的二次点击确认。（[#122](https://github.com/mantoujun12/AstrBot-Go/pull/122)）
- 前端事件订阅与轮询失败不再被静默吞掉：资源监控改为展示错误态并提供重试，日志页与任务页在订阅或列表失败时展示可重试的错误态。（[#126](https://github.com/mantoujun12/AstrBot-Go/pull/126)）
- 修复实例发现流程的进程管道问题：发现子进程不再因 stderr 管道无人读取而阻塞并被误报为不可用，超时强杀路径也不再泄漏僵尸进程。（[#125](https://github.com/mantoujun12/AstrBot-Go/pull/125)）
- 修复归档解压与网络错误消息中泄漏本地完整路径及原始 URL 的问题，并为必需备份文件缺失时的空错误信息补充具体描述。（[#120](https://github.com/mantoujun12/AstrBot-Go/pull/120)）
- 将关键缓存/配置写入改为原子操作（GitHub Releases 缓存、数据目录覆盖文件），并在新恢复开始前清理残留的 `.restore-rollback-*` 目录。（[#119](https://github.com/mantoujun12/AstrBot-Go/pull/119)）
