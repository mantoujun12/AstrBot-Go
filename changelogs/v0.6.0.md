## English

### Added

- Instances store the AstrBot WebUI login (username and password) used by the launcher's built-in chat; the credentials can be replaced or cleared from the instance form. ([#142](https://github.com/mantoujun12/AstrBot-Go/pull/142))
- Show the detected runtime version of each dependency (Python 3.10 / 3.12, Node.js, uv) on the Versions page and split the components section into one card per dependency; an installed runtime whose version cannot be detected shows an "Unknown" badge. ([#136](https://github.com/mantoujun12/AstrBot-Go/pull/136))
- Split the Tasks page into History and Scheduled sections; each scheduled task can start, stop, back up or clear the cache of an instance once, on an interval, daily or weekly while the app is running. ([#137](https://github.com/mantoujun12/AstrBot-Go/pull/137))
- Manage an instance's personas, scheduled jobs, MCP servers, config files and knowledge bases directly in the launcher, including copying them to other instances. ([#140](https://github.com/mantoujun12/AstrBot-Go/pull/140))
- Add the Extensions page with a card grid, reachable from a new sidebar entry. ([#141](https://github.com/mantoujun12/AstrBot-Go/pull/141))
- Manage plugins and Skills on the Extensions page: browse and search the official AstrBot plugin market, install into a stopped instance, enable, disable, update-check or uninstall plugins with optional cleanup of their config and data, and upload, browse, edit, toggle or batch-delete local skills, while plugin and builtin skills stay read-only. ([#159](https://github.com/mantoujun12/AstrBot-Go/pull/159))
- Add a standalone chat window opened from the top of the sidebar, with a custom title bar on Windows and Linux whose buttons stay usable while its settings dialog is open (macOS keeps the native traffic lights). ([#145](https://github.com/mantoujun12/AstrBot-Go/pull/145))
- The chat window embeds the ported ChatUI island: an "Instance & Model" panel and a composer picker switch instance and model from a flat, provider-grouped list, sessions can be renamed and deleted, a config profile can be applied to the current conversation, entries without a backend stay hidden, and the window states why it is not ready instead of showing a generic load error. ([#148](https://github.com/mantoujun12/AstrBot-Go/pull/148))
- Render chat replies with markdown, tool cards, reasoning and threaded parts, and show images, audio, video and files from history; messages carry token usage and per-message stats, regenerate streams the replacement reply, code blocks highlight a fixed whitelist of common languages, and error cards point model configuration to the instance WebUI. ([#146](https://github.com/mantoujun12/AstrBot-Go/pull/146))
- Chat appearance follows the system when chosen and stays in sync with the launcher window, the title bar and taskbar show the current session title, and the chat sidebar slides between its full and rail widths. ([#147](https://github.com/mantoujun12/AstrBot-Go/pull/147))
- The in-app WebUI tab signs in automatically: instances running AstrBot v4.27.3 or newer authenticate through the desktop-managed session exchange, and older instances fall back to the panel credentials stored in the instance settings. ([#157](https://github.com/mantoujun12/AstrBot-Go/pull/157))

### Changed

- Update frontend and Rust dependencies, including rusqlite (0.37 to 0.43), shiki (3 to 4), Tauri libraries and the release workflow actions. ([#152](https://github.com/mantoujun12/AstrBot-Go/pull/152))
- The sidebar's Chat and Extensions entries and the "Manage data" action in the instance more menu now carry a purple Beta badge. ([#161](https://github.com/mantoujun12/AstrBot-Go/pull/161))

### Fixed

- Deleting a knowledge base now removes it from the list immediately and prevents a concurrent or subsequent list refresh from restoring the deleted entry. ([#162](https://github.com/mantoujun12/AstrBot-Go/pull/162))
- The sidebar's chat entry no longer shows its right-arrow hint in the collapsed rail, so its icon stays centered instead of being squeezed. ([#160](https://github.com/mantoujun12/AstrBot-Go/pull/160))
- Switching instances while an Extensions list is still loading no longer shows the previous instance's plugins or skills. ([#163](https://github.com/mantoujun12/AstrBot-Go/pull/163))

## 中文

### 新增

- 实例可保存 AstrBot WebUI 的登录账号（用户名与密码），供启动器内置聊天使用；可在实例表单中更换或清除。（[#142](https://github.com/mantoujun12/AstrBot-Go/pull/142)）
- 版本页现在显示每个依赖的检测版本（Python 3.10 / 3.12、Node.js、uv），并将组件区按依赖拆分为独立卡片；已安装但无法检测版本的运行时显示“未知”标记。（[#136](https://github.com/mantoujun12/AstrBot-Go/pull/136)）
- 任务页拆分为“历史记录”与“定时任务”两部分：定时任务可按一次性、间隔、每天或每周运行，执行启动、停止、备份或清除实例缓存，仅在应用运行时生效。（[#137](https://github.com/mantoujun12/AstrBot-Go/pull/137)）
- 在启动器中直接管理实例的人格、定时任务、MCP 服务器、配置文件与知识库，并支持复制到其他实例。（[#140](https://github.com/mantoujun12/AstrBot-Go/pull/140)）
- 新增扩展功能页面，以卡片网格呈现，侧边栏增加对应入口。（[#141](https://github.com/mantoujun12/AstrBot-Go/pull/141)）
- 在扩展页管理插件与技能：可浏览、搜索官方插件市场并安装到已停止的实例，启用、停用、检查更新或卸载插件（可选同时删除配置与持久化数据）；也可上传、浏览、编辑、启用停用或批量删除本地技能，插件与 AstrBot 内置技能保持只读。（[#159](https://github.com/mantoujun12/AstrBot-Go/pull/159)）
- 新增独立聊天窗口，入口位于侧边栏顶部；Windows 和 Linux 上使用自定义标题栏，设置对话框打开时窗口按钮仍可点击（macOS 保留原生红绿灯按钮）。（[#145](https://github.com/mantoujun12/AstrBot-Go/pull/145)）
- 聊天窗口嵌入移植的 ChatUI：通过“实例与模型”面板与输入框选择器切换实例和模型（按提供商分组的平铺列表），支持重命名和删除会话、将配置文件应用到当前会话，后端尚不可用的入口保持隐藏，实例未就绪时直接说明原因而不是显示通用加载错误。（[#148](https://github.com/mantoujun12/AstrBot-Go/pull/148)）
- 聊天回复支持 Markdown、工具卡片、推理过程与分支内容，并可显示历史消息中的图片、音频、视频与文件；消息显示 token 用量与统计，重新生成通过流式返回替换回复，代码块仅对固定的常用语言白名单高亮，错误卡片提示模型配置需在实例的 WebUI 中完成。（[#146](https://github.com/mantoujun12/AstrBot-Go/pull/146)）
- 聊天窗口的主题与语言支持跟随系统，并与启动器窗口双向同步；标题栏与任务栏显示当前会话标题，聊天侧边栏在完整宽度与图标栏之间平滑过渡。（[#147](https://github.com/mantoujun12/AstrBot-Go/pull/147)）
- 应用内 WebUI 标签页支持自动登录：AstrBot v4.27.3 及以上的实例通过桌面托管会话交换免密登录，旧版本回退使用实例设置中保存的面板凭据。（[#157](https://github.com/mantoujun12/AstrBot-Go/pull/157)）

### 变更

- 更新前端与 Rust 依赖，包括 rusqlite（0.37 至 0.43）、shiki（3 至 4）、Tauri 相关库及发布工作流 Actions。（[#152](https://github.com/mantoujun12/AstrBot-Go/pull/152)）
- 侧边栏的“聊天”“扩展”入口及实例“更多”菜单中的“管理数据”项现在带有紫色 Beta 标记。（[#161](https://github.com/mantoujun12/AstrBot-Go/pull/161)）

### 修复

- 删除知识库后会立即从列表中移除该条目，并防止并发或后续的列表刷新将已删除项恢复显示。（[#162](https://github.com/mantoujun12/AstrBot-Go/pull/162)）
- 侧边栏聊天入口在收缩的图标栏状态下不再显示右箭头提示，图标保持居中而不被挤压。（[#160](https://github.com/mantoujun12/AstrBot-Go/pull/160)）
- 在列表仍在加载时切换实例，扩展页不再显示上一个实例的插件或技能。（[#163](https://github.com/mantoujun12/AstrBot-Go/pull/163)）
