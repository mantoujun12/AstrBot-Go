## English

### Added

- Added per-instance CPU, memory, and disk history charts with configurable threshold alerts. ([#16](https://github.com/mantoujun12/AstrBot-Go/pull/16))
- Auto-restart instances that exit unexpectedly, with exponential backoff, a configurable retry limit, and crash notifications. ([#14](https://github.com/mantoujun12/AstrBot-Go/pull/14))
- Added an instance update center with stable release checks, update badges, single-instance upgrades, and batch upgrades, while respecting the global and per-instance update toggles. ([#15](https://github.com/mantoujun12/AstrBot-Go/pull/15))
- Launcher updates can now be checked, downloaded, and installed from Settings without manually downloading a release. ([#17](https://github.com/mantoujun12/AstrBot-Go/pull/17))
- Added a unified task center for downloads, deployments, backups, and repairs, with persistent records, live progress, and cancellable downloads with pause and resume support. ([#18](https://github.com/mantoujun12/AstrBot-Go/pull/18))
- Added one-click instance health checks for Python, virtual environments, dependencies, ports, disk space, configuration, and WebUI connectivity. ([#21](https://github.com/mantoujun12/AstrBot-Go/pull/21))

### Changed

- Resource monitoring now measures the whole instance process tree, reports memory as the private working set (the value task managers show), scales CPU to the whole machine, confirms threshold alerts over two samples, and ships an enabled-by-default alert switch with persisted CPU, memory, and disk thresholds. ([#20](https://github.com/mantoujun12/AstrBot-Go/pull/20))

### Fixed

- Fixed manifests written by earlier builds being reset, which made existing instances and installed versions disappear after upgrading. ([#19](https://github.com/mantoujun12/AstrBot-Go/pull/19))

## 中文

### 新增

- 新增实例 CPU、内存和磁盘历史趋势图，并支持配置阈值告警。（[#16](https://github.com/mantoujun12/AstrBot-Go/pull/16)）
- 异常退出的实例会按次数与时间间隔退避自动重启，支持配置最大重试次数与崩溃通知。（[#14](https://github.com/mantoujun12/AstrBot-Go/pull/14)）
- 新增实例更新中心，支持检查最新稳定版、显示更新徽标、单实例升级和全部升级，并遵循全局与单实例更新开关。（[#15](https://github.com/mantoujun12/AstrBot-Go/pull/15)）
- 现在可以在设置中检查、下载并安装启动器更新，无需手动下载发布安装包。（[#17](https://github.com/mantoujun12/AstrBot-Go/pull/17)）
- 新增统一任务中心，集中展示下载、部署、备份和修复任务，并支持持久化记录、实时进度，下载任务可取消、暂停与继续。（[#18](https://github.com/mantoujun12/AstrBot-Go/pull/18)）
- 新增实例一键体检，检查 Python、虚拟环境、依赖、端口、磁盘空间、配置和 WebUI 连通性。（[#21](https://github.com/mantoujun12/AstrBot-Go/pull/21)）

### 变更

- 资源监控现在统计实例的完整进程树，内存采用专用工作集（与任务管理器一致），CPU 按整机核数换算，阈值告警需连续两次采样确认，并提供默认开启的告警开关与按实例持久化的 CPU、内存、磁盘阈值。（[#20](https://github.com/mantoujun12/AstrBot-Go/pull/20)）

### 修复

- 修复旧版本写入的清单被重置的问题，升级后已有实例与已安装版本不再丢失。（[#19](https://github.com/mantoujun12/AstrBot-Go/pull/19)）
