## English

### Added

- Added per-source network configuration for GitHub, PyPI, Node.js, npm, the Python runtime, and uv, each with a default source, preset mirrors, and a custom source. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))
- Added latency and download speed tests for network sources and the HTTP proxy. Click tests sources serially, Ctrl+click tests the selected source, and Shift+click tests sources in parallel. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))
- Added an opt-in setting that allows connectivity probes to follow DNS redirects to local or private addresses. Literal local addresses and local host names remain blocked. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))

### Changed

- Replaced the global mainland acceleration switch with per-source network configuration. Existing mainland acceleration settings are migrated to equivalent presets. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))
- Starting or restarting an instance no longer shows a blocking progress dialog; a bottom notification reports when the instance starts. ([#11](https://github.com/mantoujun12/astrbot-launcher-vue/pull/11))

### Fixed

- Improved tooltip contrast in light and dark themes and separated the network speed test shortcut hint with a blank line. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))
- Restricted connectivity probes to public HTTP(S) destinations and revalidated every redirect target. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))
- Prevented legacy migration from overwriting newer per-source network settings. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))
- Made Node.js, npm, and Python speed tests download real archives instead of metadata. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))
- Kept newly edited source selections and proxy test results accurate while a save or test is pending. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))
- Removed the white flash when the main window opens at startup by waiting for the first frontend paint, matching the window background to the active theme, and deferring tray or second-instance activation until the UI is ready. ([#9](https://github.com/mantoujun12/astrbot-launcher-vue/pull/9))

### Removed

- Removed the mainland acceleration switch. ([#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8))

## 中文

### 新增

- 新增 GitHub、PyPI、Node.js、npm、Python 运行时和 uv 的逐项网络源配置，每项提供默认源、预设镜像源和自定义源。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
- 新增网络源与 HTTP 代理的延迟和下载速度测试。点击串行测试，Ctrl+点击测试当前选中源，Shift+点击并行测试。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
- 新增“允许本地 DNS 重定向探测”选项，供连通性测试跟随解析到本地或私有地址的域名。直连本地地址和本地主机名仍会被拒绝。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）

### 变更

- 使用逐项网络源配置替代全局大陆加速开关；已有大陆加速配置会自动迁移为对应预设。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
- 启动或重启实例时不再显示阻塞式进度弹窗；启动完成后通过底部通知提示实例已启动。（[#11](https://github.com/mantoujun12/astrbot-launcher-vue/pull/11)）

### 修复

- 提升浅色与深色主题下提示框的对比度，并将网络测速提示的快捷键说明分行显示。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
- 将连通性探测限制为公网 HTTP(S) 目标，并对每次重定向重新校验目标地址。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
- 避免旧版大陆加速迁移覆盖较新的逐项网络源设置。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
- 将 Node.js、npm 和 Python 测速改为下载真实归档，不再测量元数据。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
- 保存或测试进行期间，保留用户新编辑的源选择和代理测试结果。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
- 修复启动时主窗口短暂白屏的问题：首屏渲染完成后再显示窗口，让窗口底色跟随当前主题，并让托盘或重复启动触发的显示同样等待界面就绪。（[#9](https://github.com/mantoujun12/astrbot-launcher-vue/pull/9)）

### 移除

- 移除大陆加速开关。（[#8](https://github.com/mantoujun12/astrbot-launcher-vue/pull/8)）
