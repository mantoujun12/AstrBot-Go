# Changelog

## English

### Added

- Added an "Instances" section in Settings with an enable/disable switch per instance source, powered by a pluggable instance source framework.
- Added read-only discovery of AstrBot instances deployed with Docker, listing running containers and their WebUI addresses.

## 中文

### 新增

- 设置中新增"实例"分区，可按部署来源开关实例发现，底层接入可扩展的实例来源框架。
- 新增对 Docker 部署的 AstrBot 实例的只读发现，可列出运行中的容器及其 WebUI 地址。
