# Changelog

## English

### Added

- Added an "Instances" section in Settings with an enable/disable switch per instance source, powered by a pluggable instance source framework.
- Added directory-scan instance discovery: the launcher scans configured directories for source-code deployed or legacy instances and shows them as read-only entries with a WebUI shortcut.

## 中文

### 新增

- 设置中新增"实例"分区，可按部署来源开关实例发现，底层接入可扩展的实例来源框架。
- 新增目录扫描实例发现：启动器扫描指定目录中的源码部署或旧版实例，以只读条目展示并提供 WebUI 快捷入口。
