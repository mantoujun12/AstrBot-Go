# Changelog

## English

### Added

- Added an "Instances" section in Settings with an enable/disable switch per instance source, powered by a pluggable instance source framework.
- Instances deployed through the official `uv tool` script (the `astrbot` CLI) are now detected and shown read-only, with a shortcut to open their WebUI.

## 中文

### 新增

- 设置中新增"实例"分区，可按部署来源开关实例发现，底层接入可扩展的实例来源框架。
- 现在可发现通过官方 `uv tool` 脚本部署的实例（`astrbot` 命令行），以只读方式展示并可打开其 WebUI。
