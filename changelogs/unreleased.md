# Changelog

## English

### Added

- Added a pluggable instance source framework: an "Instances" section in Settings with an enable/disable switch per source, the instance list now merges externally discovered instances (source badge, read-only, open-WebUI entry when available), and Docker-deployed AstrBot instances are discovered read-only with their WebUI addresses.

## 中文

### 新增

- 新增可扩展的实例来源框架：设置中新增“实例”分区，可按来源开关发现；实例列表合并展示外部来源实例（带来源徽标、只读、可用时提供打开 WebUI 入口）；新增对 Docker 部署实例的只读发现，可列出其 WebUI 地址。
