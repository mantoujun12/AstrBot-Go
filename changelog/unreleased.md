## 新增 / Added

- 提供 AstrBot 桌面管理器，可集中管理多个本地实例。
- 支持下载与切换 AstrBot 版本，显示实时下载速度，并可暂停、继续或取消下载；取消后会清理未完成的部分文件。
- 支持版本与组件管理。
- 支持实例数据备份与恢复；创建备份时可填写最多 200 个字符的备注，备份列表支持按备注搜索。
- 支持自动配置 Python、Node.js 与 uv 运行环境。
- 内置实例 WebUI 标签页，可同时打开多个实例页面，并支持全屏显示。
- 提供概览仪表盘、实例管理、版本管理、备份管理、实时日志和设置页面。
- 支持自定义 Windows 风格标题栏、窗口控制按钮和 Snap Layout。
- 支持自定义主题颜色，并可跟随系统深色/浅色模式。
- 支持简体中文、英文、俄文和日文四种界面语言，默认跟随系统语言，可在运行时切换并记忆偏好。
- 支持以 Markdown 渲染 AstrBot 版本更新日志。
- 支持浏览器式标签页快捷键：Ctrl+Tab、Ctrl+Shift+Tab、Ctrl+1-8、Ctrl+9、Ctrl+W 和 Ctrl+F4。

## 变更 / Changed

- 应用名称统一为 AstrBot Launcher。
- 实例标签页改为全窗口显示，进入实例时隐藏侧边栏。
- 优化窗口外壳、对话框圆角和标签页导航样式。
- 调整浅色主题背景色，移除实例 WebUI 顶部的地址行。
- 更新应用图标。

## 修复 / Fixed

- 修复窗口控制按钮被 Vuetify 对话框遮罩覆盖的问题。
- 修复启动器窗口外壳样式不一致的问题。

- 修复 GitHub 代理和 PyPI 镜像无法保存为空值的问题；空值现在表示使用官方源。
- 修复备份恢复可能中断的问题：恢复流程改为原子操作，并在恢复前自动创建安全备份。
- 修复对话框圆角与窗口外壳不协调的问题。

## 安全 / Security

- 日志中的敏感路径和 URL 会自动脱敏。
- 下载的归档在原子替换前会校验路径与内容，防止路径穿越（Zip Slip）。
