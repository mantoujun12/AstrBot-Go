## Added / 新增

- Added an AstrBot desktop manager that centralizes management of multiple local instances.
  提供 AstrBot 桌面管理器，可集中管理多个本地实例。
- Added AstrBot version download and switching with real-time download speed, pause, resume, and cancel; cancelling cleans up incomplete partial files.
  支持下载与切换 AstrBot 版本，显示实时下载速度，并可暂停、继续或取消下载；取消后会清理未完成的部分文件。
- Added version and component management.
  支持版本与组件管理。
- Added instance data backup and restore; backups can include a note of up to 200 characters, and the backup list can be searched by note.
  支持实例数据备份与恢复；创建备份时可填写最多 200 个字符的备注，备份列表支持按备注搜索。
- Added automatic configuration of Python, Node.js, and uv runtime environments.
  支持自动配置 Python、Node.js 与 uv 运行环境。
- Added built-in instance WebUI tabs that can open multiple instance pages at once, with full-screen support.
  内置实例 WebUI 标签页，可同时打开多个实例页面，并支持全屏显示。
- Added overview dashboard, instance management, version management, backup management, live logs, and settings pages.
  提供概览仪表盘、实例管理、版本管理、备份管理、实时日志和设置页面。
- Added a custom Windows-style title bar, window controls, and Snap Layout support.
  支持自定义 Windows 风格标题栏、窗口控制按钮和 Snap Layout。
- Added custom theme colors and system dark/light mode following.
  支持自定义主题颜色，并可跟随系统深色/浅色模式。
- Added Simplified Chinese, English, Russian, and Japanese UI languages; the app follows the system language by default, supports runtime switching, and remembers the preference.
  支持简体中文、英文、俄文和日文四种界面语言，默认跟随系统语言，可在运行时切换并记忆偏好。
- Added Markdown rendering for AstrBot release notes.
  支持以 Markdown 渲染 AstrBot 版本更新日志。
- Added browser-style tab shortcuts: Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+1-8, Ctrl+9, Ctrl+W, and Ctrl+F4.
  支持浏览器式标签页快捷键：Ctrl+Tab、Ctrl+Shift+Tab、Ctrl+1-8、Ctrl+9、Ctrl+W 和 Ctrl+F4。

## Changed / 变更

- Unified the application name as AstrBot Launcher.
  应用名称统一为 AstrBot Launcher。
- Changed instance tabs to full-window display and hid the sidebar when entering an instance.
  实例标签页改为全窗口显示，进入实例时隐藏侧边栏。
- Improved the window shell, dialog corner radii, and tab navigation styles.
  优化窗口外壳、对话框圆角和标签页导航样式。
- Adjusted the light theme background color and removed the address bar above the instance WebUI.
  调整浅色主题背景色，移除实例 WebUI 顶部的地址行。
- Updated the application icon.
  更新应用图标。

## Fixed / 修复

- Fixed window controls being covered by Vuetify dialog overlays.
  修复窗口控制按钮被 Vuetify 对话框遮罩覆盖的问题。
- Fixed inconsistent launcher window shell styles.
  修复启动器窗口外壳样式不一致的问题。
- Fixed the missing live log console component.
  修复实时日志控制台组件缺失的问题。
- Fixed GitHub proxy and PyPI mirror settings not being savable as empty values; an empty value now uses the official source.
  修复 GitHub 代理和 PyPI 镜像无法保存为空值的问题；空值现在表示使用官方源。
- Fixed possible backup restore interruptions by making the restore flow atomic and automatically creating a safety backup before restoring.
  修复备份恢复可能中断的问题：恢复流程改为原子操作，并在恢复前自动创建安全备份。
- Fixed dialog corner radii not matching the window shell.
  修复对话框圆角与窗口外壳不协调的问题。

## Security / 安全

- Sensitive paths and URLs in logs are automatically redacted.
  日志中的敏感路径和 URL 会自动脱敏。
- Downloaded archives are validated for paths and contents before atomic replacement to prevent path traversal (Zip Slip).
  下载的归档在原子替换前会校验路径与内容，防止路径穿越（Zip Slip）。
